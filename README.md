# Audiology Diagnostic Assessment Portal

## About the Project

The Audiology Diagnostic Assessment Portal is a web-based application developed to assist in audiology assessment and diagnosis. It provides an easy-to-use interface for managing patient information and assessment-related data.

## Technologies Used

* Python
* HTML
* CSS
* MySQL

## Main Features

* Patient information management
* Audiology assessment
* Database management
* User-friendly web interface
* Storage and retrieval of assessment data

## Purpose

The main purpose of this project is to provide a simple digital platform for managing audiology assessment-related information.

Academic Project
